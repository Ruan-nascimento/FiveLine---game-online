# Inicialização para manutenção

1. Leia `README.md`, este arquivo e `RULES.md`.
2. Leia a documentação em `docs/` ligada à área que será modificada.
3. Inspecione a estrutura, dependências e alterações existentes.
4. Verifique `supabase/migrations/` antes de alterar persistência ou autorização.
5. Rode `npm run test` para estabelecer uma linha de base.
6. Escreva um plano curto, com etapas verificáveis e sem ampliar o escopo.
7. Implemente preservando o motor puro e o servidor como fonte de verdade.
8. Rode `npm run lint`, `npm run test` e `npm run build`.
9. Se alterar banco, valide a migration com Supabase local ou projeto de teste.
10. Atualize README e a documentação específica antes de entregar.
